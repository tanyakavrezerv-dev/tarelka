# Тарелка - учебный web MVP

Планировщик питания: меню на неделю, КБЖУ, демонстрационная стоимость покупок и кладовка.

## Запуск

Приложение находится в `dist`. Откройте его через HTTP, а не через `file://`:

```powershell
.\start-local.ps1
```

После запуска откройте `http://127.0.0.1:4173/`.

## Проверки

В проекте есть чистое расчётное ядро в `core/engine.cjs`. Оно не зависит от DOM и принимает данные параметрами.

```powershell
$node = Join-Path $env:TEMP 'tarelka-node-v24.21.0.exe'
& $node --test tests/data-and-engine.test.cjs tests/recipes.test.cjs
& $node core-smoke.cjs
& $node --check dist/app.js
```

Тесты проверяют 86 продуктов, 32 рецепта, 86 цен, ссылки `productId`, эталонные КБЖУ, стоимость, упаковки и режим `per_piece` для круассана.

## Данные и допущения

- `products.seed.json` и `recipes.seed.json` являются стартовыми данными каталога.
- `prices.demo.json` содержит демонстрационные ориентиры в рублях. Это не цены из конкретного магазина и не источник для финансовых решений.
- КБЖУ приблизительные. Для рецепта используется оценочный `cookedWeightG`, который можно переопределить для записи в меню.
- Данные хранятся локально под ключом с префиксом `tarelka:v1:`.
- Экспорт и импорт работают JSON-файлом. Режим семьи, синхронизация, PWA и Telegram-бот относятся к следующим этапам.

## Структура

- `core/engine.cjs` - расчёты КБЖУ, веса, потребности, стоимости и статусов планки.
- `storage/` - зарезервированная граница для отдельного адаптера хранения.
- `ui/` - зарезервированная граница для дальнейшего разделения интерфейса.
- `dist/` - версия, которую можно опубликовать на GitHub Pages.
